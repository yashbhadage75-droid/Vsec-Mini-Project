# NoteFlow - Modern Workspace Project

NoteFlow is a production-ready, client-side note management dashboard created using HTML5, Tailwind CSS, and vanilla JavaScript.

## Features
- **Zero Database Setup**: Uses browser `localStorage` for complete CRUD operations (Create, Read, Update, Delete).
- **Modern SaaS UI**: Dark mode dashboard layout with category tags, dynamic counts, and modal interactions.
- **Search & Filter**: Real-time searching and category filtering (Work, Personal, Ideas).

## How to Run
1. Extract the ZIP file.
2. Open `index.html` directly in any web browser, or use Live Server in VS Code.
